# Rashid

A madaris donation register that runs entirely in the browser.

Search any madrasa by name, registration number, address or phone; see what
you gave in every past year; record a new donation with its exact date.

**This repository holds no data.** The register itself lives in a separate
*private* repository (`rashid-data/register.json`). The page reads and writes
it with a fine-grained GitHub token you create yourself and paste in once per
device — the token stays in that browser and is sent nowhere but GitHub.

Open it at: https://aliansaari.github.io/rashid/
